Yauhen's Android apps

Tap Install, then open the download. A newer version installs over the old one and keeps your data.

Installing for the first time
  1. Tap Install and wait for the download to finish.
  2. Open it from the notification. The first time, Android asks to allow your browser to install apps: tap Settings and switch on Allow from this source.
  3. Every app is signed with the same key as before, so it updates one installed from F-Droid or an earlier download.
APKs come from the apps release; each app's release replaces its file.
